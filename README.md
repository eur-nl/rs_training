# Research Software training at EUR
This is the GitHub repository for rs_training, a website created to host all training materials for Research Software (RS) training at Erasmus University Rotterdam (EUR).

# Upload your material
Are you a trainer at EUR? We would greatly appreciate it if you allowed us to upload your training materials here as well. It would be great if you could create a pull request with your materials. While we primarily work with .qmd files, we can also format .ipynb and .md files to fit the website.

# Tips for admins: How to upload training material
1. `install` [Quarto](https://quarto.org)
2. `open` an IDE of choice (VSCode has a handy Quarto extension)
3. `add` the content to the repository (e.g., your training .ipynb file)
4. `link` the content in the `_quarto.yml` file following the existing scheme
5. `run` `quarto render` to build the new `docs` folder
6. `commit` your changes in development branch
7. `push` all changes and resolve all merge conflicts
8. `save` the `docs` folder somewhere
9. `switch` to the main branch
10. `add` the `docs` folder to the main branch

Questions? Let our website admin (Helena Wedig) know!
